# The Shattered Keep — Godot vertical slice

Open `project.godot` in Godot 4.4 or newer and run the main scene.

This first engine milestone contains:

- A real-time isometric 3D Mooncrypt combat room
- Ironwarden movement, sword attacks, shield burst, dash, health, and hit reactions
- Animated skeleton enemies with telegraphed attacks
- Three destructible monster generators that continuously spawn enemies
- Modular stone environment, dynamic firelight, fog, glow, particles, and shadows
- Keyboard/mouse and controller input mappings

The environment and characters are built from procedural primitives so the project opens without missing asset imports. They are placeholders for authored modular art, not the final visual target.
